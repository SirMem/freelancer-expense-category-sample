# Freelancer Expense Category Starter — Free Sample

A complete, usable **one-month expense log** with Schedule C–style categories. Structural seam of the paid **Freelancer Expense Tracker** — same quality Categories + Expense core, not a crippled demo.

## What's inside

| Sheet | Role |
|-------|------|
| **Start Here** | TOC seam map + gap questions (SCHEDULEC / MILEAGE / DASHBOARD) |
| **Categories** | Editable category list (common Schedule C line labels) |
| **Expense Log (One Month)** | Date / vendor / description / category / amount / business-use % → auto deductible + month totals by category |

- EXAMPLE rows only (fictional vendors) — replace with your own.
- Yellow cells are inputs; Deductible / Year / Month are formulas.
- Hand-check on sample data: **spent $422.69** · **deductible $369.69** (phone 60%, meals 50%).

## What this sample does **not** do

It does **not** include Mileage, Settings (tax year / mileage rate), a full-year Expenses grid, or a Dashboard. Those live in the paid Freelancer Expense Tracker.
